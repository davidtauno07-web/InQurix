# InQurix user guide

## First start

1. Click **Get started** and choose the folders InQurix may read (for example *Documents\Finance*). Nothing else on the computer is read.
2. Indexing runs in the background; the status in the bottom-left corner shows progress. You can pause it at any time.

## Quick Search

Press **Ctrl + Shift + Space** (Windows) or **⌘ + Shift + Space** (macOS) from anywhere.

| Key | Action |
|---|---|
| Type | Search as you type |
| ↑ / ↓ | Move between results |
| Enter | Open the document |
| Ctrl/⌘ + Enter | Show it in its folder |
| Ctrl/⌘ + Backspace | Clear the search |
| Esc | Close |

Try: `INV-1048`, `14,317.50`, `Kavango`, `invoices from March`, `contract with automatic renewal`.

## Workspace

- **Search** shows each result with *why it matched*, the exact page/cell/slide, extracted fields (amounts, dates, references, bank details) and related documents.
- **Investigations**: choose a check (e.g. *Duplicate payments*), optionally limit it to one supplier, and click **Run**. Open a finding to see the side-by-side comparison, the calculation, the evidence and what to verify. Mark it **Confirmed issue**, **Not an issue** or **Resolved**, add a note, set a reminder for a date, or export the report.
  Asking a question in Search like *"did we pay Kavango twice"* offers to open the matching investigation.
- **History & saved**: recent searches, saved searches and pinned documents. History can be turned off in Settings.
- **Sources & indexing**: add or remove folders, exclusions, pause/resume, and files that need attention (unreadable, encrypted, too large, refused).
- **Settings**: shortcut, start at login, OCR, meaning-based search, reminders, history.

## Reading findings

Findings are **evidence to review, not conclusions**. "Not found" means not found in the folders InQurix may read: the document may exist elsewhere. Bank-detail changes and suspicious emails should always be verified with the supplier using contact details you already trust, never the ones in the suspicious message.
